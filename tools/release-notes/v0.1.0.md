**The Last of Us Remastered: PC port**, first release.

Runs the PS4 game (CUSA00552, update 1.11) natively on Windows. The game's own x86-64 code runs
directly on the PC; a runtime supplies the PS4 system libraries and a Vulkan renderer (the shadPS4
video core) runs its GPU work.

> **No game files are included.** You need your own decrypted copy of the game and its update. This
> project is not affiliated with Sony Interactive Entertainment or Naughty Dog.

## Install

1. Download **TLOU-Remastered-windows.zip** below and extract it to a folder with plenty of free space.
2. Open **TLOU Launcher.exe**.
3. Click **Folders** and choose **Game files**: the folder with `eboot.bin`. Update 1.11 is looked
   for beside it, in the folder of the same name ending in `-patch` (`CUSA00552` and `CUSA00552-patch`).
4. Click **Play**. The first start takes longer while shaders compile, and you may see stutters
   until they are in the cache.

Windows 10/11 (64-bit), a Vulkan 1.3 graphics card with a current driver, and a CPU with AVX, F16C,
BMI1, MOVBE and LZCNT (Intel Haswell or newer, any AMD Ryzen). Nothing else needs installing.

## What to expect

Measured on one laptop (Core i7-8750H, GTX 1050 Ti Mobile): 60 FPS in light areas and about
40-44 FPS in the heaviest area tested. The limit there is the CPU, so lowering the resolution
barely helps. If motion feels uneven, try the **30 FPS limit** in the launcher.

## Known issues

- NPCs sometimes move in jumps. It comes and goes between runs; the cause is not settled.
- The HUD of the item inspection screen does not show.
- Short pauses the first time an area is played, while its shaders compile.
- DLSS and FSR 4 are not in this package: DLSS falls back to FSR 3.
- Tested on one PC, without a full playthrough.

When reporting a problem, attach `analysis\tlou\boot.log` (**Open log** in the launcher).
